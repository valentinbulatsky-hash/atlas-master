# Атлас мастера 0.1.3.1 — тестовая сборка

Для Windows 10 и 11, x64. В архиве только самостоятельный установщик `AtlasMaster-0.1.3.1-x64-Setup.exe`. Закройте приложение, распакуйте ZIP и установите обновление поверх предыдущей версии. Кампании и вложения сохраняются.

## Новое в 0.1.3.1

- Прозрачность фона кампании от 0 до 100%, по умолчанию 50%. Настройка работает для стандартных и загруженных фонов, отображается в предпросмотрах ПК и телефона, сохраняется и переносится вместе с кампанией.
- Название метки можно показывать сверху или снизу маркера. Доступны четыре локальных шрифта, жирное, курсивное, подчёркнутое и зачёркнутое начертание, размер 10–36 px, цвет текста с чёрным и белым вариантами. Пустые названия допустимы.
- Журнал сессий находится непосредственно под поиском в боковом меню; доступ с главной страницы кампании сохранён.
- «Руководство мастера» внизу меню: восемь глав о функциях приложения, пошаговые инструкции и доступные сочетания клавиш.
- Ctrl+B в редакторе текста не сворачивает боковое меню.

Изменения 0.1.3 (темы, формы доски, восемь форм меток и поля NPC) также входят в эту сборку. GitHub Release будет опубликован после пользовательской проверки.

Публичное название версии — **0.1.3.1**. Внутренний npm SemVer — `0.1.3+build.1`, версия сборки Windows — `0.1.3.1`.
