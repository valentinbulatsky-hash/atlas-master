# Атлас мастера — Windows 10/11

Локальный инструмент мастера D&D: кампании, статьи, персонажи, карты и доски связей. Версия **0.1.1** — первый выпуск для проверки на целевом компьютере. Работает без сервера и регистрации.

## Скачать и запустить

Откройте **Releases** этого репозитория → **Assets** → `AtlasMaster-0.1.1-Windows-x64.zip`. Архивы `Source code` содержат исходники, а не готовую программу.

1. Распакуйте **весь архив** в отдельную папку.
2. Откройте папку `AtlasMaster` и запустите `Атлас мастера.exe`.
3. Создайте кампанию или загрузите файл `.atlas.json`.

Все файлы из архива должны оставаться рядом с EXE. Node.js и Electron устанавливать не требуется. ZIP-версия не является установщиком. Программа пока не подписана цифровой подписью издателя.

## Реализованные функции

### Кампании и материалы

- Главная страница со списком кампаний, создание отдельных кампаний.
- Возврат на главную по логотипу «Атлас мастера»; боковая панель отображается внутри кампании.
- Вложенные каталоги, поиск материалов по названию и фильтрация по каталогу.
- Статьи с форматированием, изображениями, внутренними и внешними ссылками.
- Раздел «Материалы» содержит только статьи; персонажи, карты и доски открываются отдельно.
- Режим чтения и отдельная кнопка редактирования.
- Явное сохранение и предупреждение о выходе с несохранёнными изменениями.

### Персонажи

- Раздельные списки игровых персонажей и NPC.
- Портрет, описание, роль, мотивация и заметки мастера.
- Прикрепление PDF, просмотр всех страниц, выбор документа, увеличение и открытие оригинала.
- До 10 PDF на персонажа; до 10 МБ и 50 страниц на документ.

### Карты

- Загрузка изображения карты, масштабирование и перемещение.
- Метки с привязкой к материалам кампании.
- Описание карты с форматированием и ссылками.

### Доски связей

- Свободные заметки и блоки, связанные с материалами кампании.
- Формы, цвета, краткие описания; название по связанной записи или вручную.
- Выбор категории и материала для ссылки; просмотр содержимого блока.
- Изменение размеров перетаскиванием, одинаковый исходный размер блоков.
- Типы и цвета линий, указатели на обоих концах, положение подписи.
- Привязка к сетке, магнитное выравнивание и сопряжение связей.
- Отдельные режимы чтения и редактирования доски.

### Оформление и локальная работа

- Светлая и тёмная темы.
- Стандартные фоны кампании, загрузка JPEG/PNG, предпросмотр для ПК и мобильного экрана.
- Экспорт и импорт `.atlas.json` с вложениями и внутренними ссылками; перенос с сайта.
- Локальное хранение кампаний, изображений и PDF без учётной записи.
- Настройки: тема, масштаб, полный экран, папка данных, команды работы с текстом, версия и выход.
- Системное меню удалено; настройки доступны из боковой панели и по значку на главной странице.
- Последние семь снимков базы при запуске. Они не включают вложения.

## Данные, перенос и ограничения

Личные кампании, листы персонажей и «Междуземье» в дистрибутив не включены. Для переноса сохраните кампанию на сайте в `.atlas.json`, затем загрузите файл в приложении.

Данные остаются в профиле Windows при обновлении программы. Путь, резервное копирование и подробности: [desktop/README.md](desktop/README.md).

Пределы переноса: 100 МБ на файл кампании, 60 МБ вложений, 500 материалов и 300 вложений. Для полной резервной копии экспортируйте кампании или после закрытия приложения скопируйте всю папку данных. Внешние ссылки требуют интернет.

Пока нет журнала сессий, обратных ссылок и автоматического графа, истории правок, корзины, учёта тайн и улик, трекера боёв, режима игрока, совместного редактирования и облачной синхронизации. Предложенные дополнения не входят в реализованные функции.

Сборка и автоматические проверки пройдены; полная проверка GUI на реальных Windows 10/11 ещё требуется. [Описание выпуска](RELEASES.md).

## Сборка из исходников

Требуется Node.js 24. Из корня проекта:

```powershell
npm install --ignore-scripts
npm ci --prefix desktop
npm run desktop:build
npm run desktop:test
npm run desktop:start
```

На Windows `npm run desktop:win` создаёт установщик в `desktop/release`. GitHub Actions **Windows desktop** собирает и проверяет приложение на Windows. Первый push в `main` автоматически публикует новый номер версии в Releases: установщик, ZIP, исходники, инструкцию и SHA-256. Уже опубликованный выпуск не перезаписывается; для следующего выпуска нужно повысить версию в `desktop/package.json` и обновить `RELEASES.md`. Ручной **Run workflow** только собирает артефакт, если не включить параметр **publish**. Публикация запускается лишь после успешных проверок; для неё используются встроенные права Actions, личный токен не нужен.

Electron, React/TypeScript, Tiptap, React Flow, SQLite через sql.js. Исходники веб-версии сохранены для совместимости; её авторизация и инфраструктура при локальном запуске не используются.
