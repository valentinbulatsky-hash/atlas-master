# Атлас мастера — локальная версия 0.1.1

Приложение для Windows 10 и 11, x64. Работает без сервера и регистрации.

## Запуск ZIP-версии

1. Распакуйте весь архив `AtlasMaster-0.1.1-Windows-x64.zip` в отдельную папку.
2. Откройте папку `AtlasMaster` и запустите `Атлас мастера.exe`.
3. Создайте кампанию или загрузите существующий файл `.atlas.json`.

Все файлы из архива должны оставаться рядом с программой: перенос одного EXE не работает. Устанавливать Node.js или Electron пользователю не требуется.

Первая версия не подписана цифровой подписью издателя. Windows может показать предупреждение о неизвестном издателе. Сопоставьте SHA-256 архива с файлом `SHA256SUMS.txt` перед запуском.

## Обновление 0.1.1

Исправлена сборка стилей: боковая панель расположена слева, сворачивается и открывается кнопкой в шапке. Восстановлено оформление кнопок, списков и диалогов.

Системное меню «Атлас мастера / Правка / Вид / Помощь» убрано. Вместо него в нижней части боковой панели есть «Настройки приложения» с разделами:

- Оформление: тема, масштаб интерфейса, полноэкранный режим.
- Данные и файлы: открытие папки данных, сведения о резервных копиях.
- Работа с текстом: отмена, повтор, вырезание, копирование, вставка и выделение всего.
- О приложении: версия и выход.

Настройки используют те же цвета, шрифты и элементы интерфейса. На главной странице без боковой панели они доступны по значку справа сверху. Открытие настроек не отменяет правки материала; команды работы с текстом возвращают фокус в последний редактор.

## Как обновить

Закройте версию 0.1.0. Распакуйте новый архив в отдельную папку и запустите новый EXE. Данные остаются в прежней папке `%APPDATA%\AtlasMaster\data` и должны открыться автоматически. Повторно импортировать кампании не нужно. Перед обновлением можно сохранить резервный файл кампании.

## Что сохранено

- Главная страница и создание отдельных кампаний.
- Вложенные каталоги и статьи с форматированием, изображениями, внутренними и внешними ссылками.
- Отдельные разделы игровых персонажей и NPC, портреты, PDF и просмотр страниц.
- Карты с изображением, описанием и метками.
- Доски связей: формы и цвета блоков, изменение размеров, ссылки, линии и указатели, подписи, сетка и магнитное выравнивание.
- Чтение и отдельное редактирование, предупреждения о несохранённых изменениях.
- Светлая и тёмная темы, фоны кампаний и предварительный просмотр.
- Экспорт и импорт `.atlas.json` вместе с вложениями и внутренними ссылками.

Это локальная коллекция текущего пользователя Windows. Вход через ChatGPT и облачная синхронизация не используются. Другие мастера устанавливают свою копию; кампании передаются файлами.

## Перенос с сайта

На сайте откройте кампанию и нажмите сохранение в файл. В приложении выберите загрузку кампании и укажите полученный `.atlas.json`. Кампанию «Междуземье» нужно перенести этим способом: её личные данные не включены в общий дистрибутив.

## Хранение и резервные копии

Данные: `%APPDATA%\AtlasMaster\data`. Папку можно открыть через «Настройки приложения» → «Данные и файлы».

- `atlas.sqlite` — материалы и структура кампаний.
- `files` — изображения, PDF и страницы листов персонажей.
- `backups` — последние семь снимков базы, создаваемых при запуске. Это **только база**, не полная резервная копия вложений.

Для полноценной копии используйте экспорт каждой кампании или, закрыв приложение, скопируйте всю папку `data` на другой носитель. Обновление приложения заменяет программу, а данные остаются в профиле Windows. Автоматические снимки на том же диске не защищают от поломки диска.

Сохранение изменений выполняется кнопкой «Сохранить», как на сайте. При закрытии окна с несохранёнными изменениями появляется подтверждение. Сохранение файла кампании вызывает системное окно выбора пути.

Ограничения переноса сохранены: файл кампании до 100 МБ, вложения в одном экспорте до 60 МБ, до 500 материалов и 300 вложений. Отдельный PDF/файл до 10 МБ, PDF до 50 страниц. Изображения, загруженные в приложение, доступны без интернета; внешние ссылки требуют интернет.

## Сборка из исходников

Нужен Node.js 24. Из корня проекта:

```powershell
npm install --ignore-scripts
npm install --prefix desktop
npm run desktop:build
npm run desktop:test
npm run desktop:start
```

На Windows установщик собирается командой `npm run desktop:win`. Результат — в `desktop/release`. Исходники также включают GitHub Actions: вкладка Actions → Windows desktop → Run workflow; готовый EXE появляется в артефакте `AtlasMaster-Windows-x64`.

Для обновления меняется версия в `desktop/package.json`. Перед обновлением сохраните копию кампаний. Сборка не содержит кампаний и данных пользователей.

## Проверки выпуска

Сборка интерфейса и API, TypeScript, семь тестов локального хранения и API, проверки досок и переноса кампаний пройдены. Проверены перезапуск, статьи/PC/NPC/карты/доски, изображения/PDF, перенос внутренних ссылок, контрольные суммы, повторный импорт, откат транзакций и отказ записи на диск, сохранность повреждённой базы.

Windows x64 дистрибутив собран из Linux. Установщик NSIS здесь не собран из-за отсутствия Wine; его сборка предусмотрена на Windows и в GitHub Actions. Добавлены проверки генерации стилей панели и настроек, удаления меню, ограничений команд и сохранения масштаба. Проверка интерфейса в GitHub Actions дополнительно проверяет положение и сворачивание панели, настройки и смену темы. GUI-проверка в Linux заблокирована ограничением среды на системные сокеты. Реальный запуск GUI, диалогов файлов, PDF и перетаскивания на Windows 10/11 в этой среде не проверен. Это первый выпуск для проверки на целевом компьютере.
